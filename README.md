# ⌨️ Silakka 54 — Keyboard Configuration

Repositório dedicado às minhas configurações e mapeamentos personalizados para o **Silakka 54** (teclado ergonômico split de 54 teclas), focado em ergonomia, produtividade e otimização para desenvolvimento.

---

## 📐 Sobre o Hardware

* **Modelo:** Silakka 54
* **Tipo:** Split Keyboard (Ergonômico dividido)
* **Quantidade de Teclas:** 54 teclas
* **Firmware:** VIAL / QMK
